
# CEF2 Project

## Overview

This project is designed as the final assignment for the Data Skills module of the Computational Economics Foundation (CEF) course. The primary goal of the project is to analyze and predict outcomes based on a given dataset, demonstrating proficiency in data processing, model training, evaluation, and result generation. The project is structured into several directories to ensure clarity and ease of use.

### Key Components:
- **Data Processing**: Cleaning, transforming, and preparing the dataset for analysis.
- **Exploratory Data Analysis (EDA)**: Conducted by **Xinlei Hao**, this phase involves visualizing and understanding the dataset to uncover patterns and insights.


- **Model Implementation**: **Jinzhan Lin** and **Haoyuan Wei** are responsible for developing and training predictive models, including feature engineering, model selection, and hyperparameter tuning.
- **Evaluation and Results**: Assessing model performance and generating predictions, which are saved for further analysis.

### Team Roles:
- **Xinlei Hao**: Responsible for Exploratory Data Analysis (EDA) & implementing the MASTER model.
- **Jinzhan Lin and Haoyuan Wei**: Mainly responsible for model implementation, training and forecasting.

The project is organized into the following directories:
- **data**: Contains the raw datasets and related documentation.
- **processed_data**: Stores the cleaned and processed datasets.
- **models**: Contains trained models and related files.
- **notebooks**: Includes Jupyter notebooks for EDA, model training, and analysis.
- **preds**: Contains prediction results generated by the models.

This structured approach ensures a clear workflow and facilitates collaboration among team members.

## Getting Started

### Prerequisites
Before running the project, ensure you have the following installed:
- Python 3.11.7
- Libraries listed in `requirements.txt`

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MengZhiyi01/CEF2_project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CEF2_project
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Run the project
Please follow these steps to run the project:

1. **Download Raw Data**
   - Navigate to the `data` folder.
   - Follow the instructions in `data/README.md` to download the raw data and save it to the specified path.

2. **Run Exploratory Data Analysis (EDA) Notebooks**
   - Go to the `notebooks` folder.
   - Execute the following notebooks sequentially: 
     - `notebooks/EDA_Part1.ipynb`
     - `notebooks/EDA_Part2.ipynb`
     - `notebooks/EDA_Part3_fillna.ipynb`
   - These notebooks contain the full EDA workflow. Note that the uploaded notebooks already include results based on the full dataset, which you can review before running them.

3. **Processed Data Storage**
   - After running `notebooks/EDA_Part3_fillna.ipynb`, the processed data will be saved as `.parquet` files in the `processed_data` folder.
   - Additionally, the `processed_data` folder contains pre-stored sample datasets for your convenience. Refer to `processed_data/README.md` for more details.

4. **Run Models**
   - Execute **the model notebooks** located in the `notebooks` folder. These models read the data from the `processed_data` folder.
   - Pre-trained models are available in the `models` folder. You can use these pre-trained models to continue training with smaller test samples for efficiency.

## Usage

1. **Data Preparation**: Place raw data in the `data/` directory and run the EDA notebooks to clean and preprocess the data.
2. **Model Training**: Use the notebooks in the `notebooks/` directory to train and evaluate models.
3. **Prediction**: Load trained models from the `models/` directory and generate predictions, which will be saved in the `preds/` directory.
4. **Analysis**: Analyze the results using the processed data in `processed_data/` and the predictions in `preds/`.

### Data Preparation
- Place your raw datasets in the `raw_data/` directory.
- Refer to `raw_data/README.md` for details on the dataset structure and format.
- Processed datasets are stored in the `processed_data/` directory.

### Model Training
- Use the scripts in the `models/` directory to train or load models.
- Example:
  ```bash
  python models/tabm_reference.py
  ```

### Exploratory Data Analysis (EDA)
- Open the notebooks in the `notebooks/` directory to explore the dataset:
  - `EDA_Part1.ipynb`
  - `EDA_Part2.ipynb`
  - `EDA_Part3_fillna.ipynb`

### Running Experiments
- Use the notebooks in the `notebooks/` directory to run experiments or compare models:
  - `BayesianRidge.ipynb`
  - `LightGBM.ipynb`
  - `Ridge+Lasso+ElasticNet.ipynb`
  - `xgb_nn_demo.ipynb`
  - `MASTER_model.ipynb`

### Generating Predictions
- Predictions generated by the models are saved in the `preds/` directory.
- Example:
  ```python
  import pickle
  with open('preds/xgn_nn_preds.pkl', 'rb') as f:
      predictions = pickle.load(f)
  ```
