# Data Folder

This folder is intended to store the raw datasets required for the project. However, due to the large size of the datasets, they are not included in this repository. Instead, you can download the datasets using the following methods:

## Download Instructions

### Option 1: Download from Kaggle

The raw datasets are available on Kaggle. Please follow the steps below to download them:

1. **Visit Kaggle**:
   - Go to the Kaggle website and search for the dataset by its name or ID.
   - [Kaggle Dataset Link](https://www.kaggle.com/competitions/jane-street-real-time-market-data-forecasting)

2. **Download the Dataset**:
   - Click the "Download" button on the Kaggle dataset page.
   - After downloading, place the dataset files in the `data` folder.
